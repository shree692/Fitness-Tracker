VitalTrack is a sleek, mobile-first fitness and calorie tracker designed to help users monitor daily nutrition, activity, hydration, and progress toward fitness goals. The project is implemented as a lightweight single-page web app with a modern dashboard-style interface.

## Overview

This application gives users a simple way to:

- log food intake and calories consumed
- track workouts and calories burned
- monitor water intake
- check daily step progress
- adjust calorie and step goals
- update personal profile details

## Features

- Dashboard with net calorie balance and key stats
- Food log with meal type and calorie entries
- Activity log for workouts and burned calories
- Water intake counter with percentage progress
- Steps tracking and progress indicator
- Adjustable daily calorie and step targets
- Profile editor for user details
- Reset feature to clear the day’s tracking data
- Responsive mobile UI inspired by fitness apps

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## How to Run

### Option 1: Open directly

Open [index.html](index.html) in a browser.

### Option 2: Run a local server

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Screens and Functionality

- Dashboard: overview of calories consumed, burned, remaining, water, and steps
- Calories tab: log meals and view total intake
- Activity tab: record workouts and calorie burn
- Goals tab: set daily goals and monitor progress
- Profile tab: update user data and daily target

## Notes

This project is built as a front-end demo and uses browser memory for data storage while the page remains open. It does not include a backend, authentication, user database, or cloud sync.
